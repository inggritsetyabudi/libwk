# wk source list — the single source of truth for every
# compilable source file. CMake (cmake/wk_sources.cmake),
# web/build.sh and web/build.ps1 all read this file; no
# other place lists sources. One path per line, relative
# to the repository root. Blank lines and lines starting
# with # are ignored. Sections are matched by name.
#
# A file added to the tree without an entry here fails
# the configure-time drift check; a listed file that does
# not exist fails the read. Add a file in exactly one
# place: the section it belongs to.
